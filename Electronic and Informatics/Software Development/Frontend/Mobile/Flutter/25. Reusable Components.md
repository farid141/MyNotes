# Reusable Component

Cara yang paling umum di Flutter untuk bikin button reusable adalah **bungkus widget itu jadi custom widget sendiri**, lalu expose properti yang memang sering berubah (text, onPressed, loading state, warna, ukuran, icon, dll).

Kalau sekarang kamu sering pakai ini:

```dart
SizedBox(
  width: double.infinity,
  child: ElevatedButton(
    onPressed: generateSBG,
    child: const Text('Generate SBG'),
  ),
)
```

Bisa dijadikan komponen reusable seperti ini:

```dart
class AppButton extends StatelessWidget {
  final String text;
  final VoidCallback? onPressed;
  final bool isLoading;

  const AppButton({
    super.key,
    required this.text,
    required this.onPressed,
    this.isLoading = false,
  });

  @override
  Widget build(BuildContext context) {
    return SizedBox(
      width: double.infinity,
      child: ElevatedButton(
        onPressed: isLoading ? null : onPressed,
        child: isLoading
            ? const SizedBox(
                height: 18,
                width: 18,
                child: CircularProgressIndicator(strokeWidth: 2),
              )
            : Text(text),
      ),
    );
  }
}
```

Cara pakai:

```dart
AppButton(
  text: 'Generate SBG',
  onPressed: generateSBG,
)
```

Kalau loading:

```dart
AppButton(
  text: 'Generate SBG',
  onPressed: generateSBG,
  isLoading: true,
)
```

Ini sudah cukup clean untuk kebanyakan app.

## Lebih Scallable (dengan tambahan param style)

Biasanya pakai enum untuk type, lalu state aktif/nonaktif dikontrol lewat boolean. Di Flutter, ini cukup idiomatis.

Contoh yang clean:

```dart id="2n3z0f"
enum ButtonType {
  primary,
  secondary,
  danger,
}
```

Reusable button:

```dart id="m9s4tk"
class AppButton extends StatelessWidget {
  final String text;
  final VoidCallback? onPressed;
  final ButtonType type;
  final bool isActive;
  final bool isLoading;

  const AppButton({
    super.key,
    required this.text,
    required this.onPressed,
    this.type = ButtonType.primary,
    this.isActive = true,
    this.isLoading = false,
  });

  Color _backgroundColor() {
    switch (type) {
      case ButtonType.primary:
        return Colors.purple;
      case ButtonType.secondary:
        return Colors.grey.shade300;
      case ButtonType.danger:
        return Colors.red;
    }
  }

  Color _textColor() {
    switch (type) {
      case ButtonType.primary:
      case ButtonType.danger:
        return Colors.white;
      case ButtonType.secondary:
        return Colors.black;
    }
  }

  @override
  Widget build(BuildContext context) {
    final enabled = isActive && !isLoading;

    return SizedBox(
      width: double.infinity,
      child: ElevatedButton(
        onPressed: enabled ? onPressed : null,
        style: ElevatedButton.styleFrom(
          backgroundColor: _backgroundColor(),
          foregroundColor: _textColor(),
          disabledBackgroundColor: Colors.grey.shade400,
        ),
        child: isLoading
            ? const SizedBox(
                height: 18,
                width: 18,
                child: CircularProgressIndicator(
                  strokeWidth: 2,
                  color: Colors.white,
                ),
              )
            : Text(text),
      ),
    );
  }
}
```

### Pemakaian

```dart id="x8r0tp"
AppButton(
  text: 'Save',
  onPressed: saveData,
)

  text: 'Cancel',
  type: ButtonType.secondary,
  onPressed: cancel,
)
```
