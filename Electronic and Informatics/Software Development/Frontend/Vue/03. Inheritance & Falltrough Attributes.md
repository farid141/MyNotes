# Inheritance / Falltrough Attribute

Merupakan sebuah pewarisan ketika `atribut tidak diterima sebagai props` oleh child.

Ini berlaku untuk atribut:

- class
- style
- id
- attribute HTML lain
- event listener (@click dll)

Falltrough atribut akan diwariskan ke root elemtn **`Tapi dengan syarat`** kalau hanya ada satu root element

## Attribute Inheritance

Secara default, atribut tidak didefinisikan props pada child `akan diwarisi otomatis` ke child dan ditempel ke **root/wrapper element**, jika pada komponen child sudah memiliki attribute (`style dan class`), akan di gabung.

```HTML
<!-- ParentComponent.vue -->
<template>
  <ChildComponent id="child-id" class="parent-class" />
</template>

<!-- ChildComponent.vue -->
<template>
  <div class="child-class">Hello from Child</div>
</template>

<!-- Output -->
<div id="child-id" class="child-class parent-class">Hello from Child</div>
```

## Directive Inheritance

Hanya berlaku untuk `event`: seperti `v-on`, `@click`.

Sedangkan `v-for` `v-if` tidak akan diwarisi oleh child.

## Mengendalikan Falltrough/Unhandled

Default behavior falltrough attribute adalah jatuh ke root element.

- Bagaimana jika kita ingin mengendalikannya?
- Bagaimana jika tidak support (root element > 1) tapi ingin tetap mengaksesnya?

Untuk menjawab hal tersebut kita dapat melakukan:

- Panggil method `defineOptions` dan berikan obj berisi `inheritAttrs: false`
- Gunakan `$attrs` ke element yang diinginkan untuk mewarisi attrs.

```javascript
<script setup>
defineOptions({
  inheritAttrs: false
})
</script>

<template>
  <div class="btn-wrapper">
    <button class="btn" v-bind="$attrs">Click Me</button>
  </div>
</template>
```
